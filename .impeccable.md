## Design Context

### Users
Windows users adjusting the brightness of a TCL 27C2A from the system tray.

### Brand Personality
Native, calm, lightweight. Controls should feel familiar and respond immediately.

### Aesthetic Direction
Sleek Windows 11. Use Segoe UI typography, restrained spacing, rounded native window corners, a dark surface, and a Windows-style accent slider. Keep accessible native control semantics.

### Design Principles
- A compact monitor selector, percentage, and slider. No explanatory footer.
- Show which monitor and which brightness mode will change.
- Native Rust/Win32, no browser runtime, telemetry, or network calls.
- Support keyboard control and display scaling.
- Do not alter other monitors or silently switch targets when one disconnects.
